# 🌿💜 HEART OF THE VERDANT PATH (JOUW VERSIE)

### 🧭 PASSIVE

- Advantage op Survival checks in de jungle
- Ze kunnen niet verdwalen
- De core wijst altijd richting de dragon lair

---

# 🩸 CORRUPTION (JOUW HOOK)

**Elke keer dat ze een Survival check doen met advantage van de core:**

→ rol een d6

---

## 🎲 EFFECTEN

**1–2:**  
Neem 1d6 necrotic damage  
Aders kleuren paars voor even

**3–4:**  
Geen effect

**5:**  
Kort gefluister in je hoofd  
→ disadvantage op eerstvolgende Wis save

**6:**  
De core pulseert hard  
→ je voelt je even “geleid”  
→ +1d4 op volgende roll (attack/save/ability)
